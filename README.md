# IELTS Zero to Band 8 🎯

A Bengali-friendly, beginner-to-IELTS study roadmap with lessons, practice activities, quizzes, and local progress tracking.

## Run it
Open `index.html` in any modern browser. No build step or API key required.

## Features
- 3 learning stages: Foundation, IELTS Skills, and Band 7–8 Practice
- 24 guided lessons with practical tasks
- Daily study plan and progress tracking saved in browser local storage
- Quick vocabulary and grammar practice
- Writing checklist and speaking prompts

## Important note
This is a learning companion, not an official IELTS product. Band 8 depends on consistent practice and performance across all four skills. Use official IELTS materials for exam-format practice.

## Deploy
Enable GitHub Pages in **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
